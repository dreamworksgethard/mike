# Mike Wazowski — $MIKE

Viral meme-coin landing page for **$MIKE** on Robinhood Chain.

## Quick start

```bash
npm install
npm run dev
```

## Configure

Edit `src/config/site.ts`:

- `X_URL` — your X/Twitter profile
- `BUY_URL` — buy / swap link
- `CONTRACT_ADDRESS` — optional; shows a copyable chip when set
- `totalSupply`, `tax`, `tokenomics` — placeholder allocations until confirmed

## Stack

React · Vite · Tailwind CSS v4 · Framer Motion
